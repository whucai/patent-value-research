# 数据交接要求

## 最小可运行数据包

### 1. 专利主表 `patents`

必要字段：稳定专利 ID、申请号、公开号、专利类型、标题、摘要、权利要求文本、申请日、公开日、授权日、IPC/CPC、申请人原名、发明人原名、PCT/同族标识。

### 2. 引文表 `citations`

必要字段：引用专利 ID、被引专利 ID、引用来源、引用日期或引用专利公开日、申请人/审查员来源标记（如有）。

### 3. 法律事件表 `legal_events`

必要字段：专利 ID、事件代码、事件名称、事件日期、法律状态、年费/维持信息。

### 4. 转让与许可表 `transactions`

必要字段：专利 ID、事件类型、登记日期、转让方、受让方/被许可方、金额与币种（如有）、合同或公告标识、权利人变更前后信息。

### 5. 主体消歧表 `entities`

必要字段：原始主体名、标准主体 ID、标准名称、主体类型、高校类型、所属城市/省份、更名或合并有效期。发明人若已有稳定 ID 一并提供。

### 6. incoPat 评分表 `incopat_scores`

必要字段：专利 ID、质量等级/分数、评分日期、数据导出日期、可获得的指标构成或版本说明。

### 7. 字段字典 `data_dictionary`

每个字段至少说明：表名、字段名、类型、含义、单位、缺失编码、来源、首次可用时点、是否可能由未来事件计算。

## 推荐文件格式

- Parquet 优先；CSV 可接受但须使用 UTF-8。
- 大表按自然键或年份分区，不拆分同一专利的单条记录。
- 日期统一为 `YYYY-MM-DD`；未知日不要填 `01` 伪造精度。
- 同一专利 ID 必须跨表稳定；另附 100–1,000 行脱敏样例用于快速审计。

## 首轮只需提供

1. 字段字典；
2. 每张表 100–1,000 行样例；
3. 各表总行数、最早/最晚日期和文件路径；
4. 专利主表与交易表的 ID 匹配率；
5. 数据是否包含全部中国高校，以及高校识别规则。

## 可选外部数据

Technovation 扩展优先获取：高校 TTO/国家技术转移机构名单与设立年份、高校研发经费和产学合作收入、城市市场化与产业结构、企业专利组合与工商属性、明确的权属或开放许可政策试点名单。
